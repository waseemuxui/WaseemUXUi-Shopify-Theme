# Waseem UXUi 2.0 – Shopify Theme

**Waseem UXUi 2.0** is a modern, fast, and highly customizable Shopify 2.0 theme designed to offer a seamless user experience with powerful features for high-converting eCommerce stores. Built with performance and design in mind, this theme is perfect for brands looking to deliver a sleek, responsive, and optimized online shopping experience.

## Features

- 🔧 **Shopify Online Store 2.0 Compatible**
- 🎨 Fully Customizable Sections & Blocks
- ⚡ Optimized for Speed and Performance
- 🌙 Light & Dark Mode Support
- 🛒 Mega Menu and Sticky Header
- 📱 100% Mobile Responsive
- 📦 AJAX Cart & Quick Add
- 🔍 Advanced Product Filtering (Collection Page)
- 🖼️ Image Zoom, Hover Effects, and Lightbox
- 🔒 GDPR & Cookie Consent Ready
- 💬 Built-in Reviews, FAQs, and Contact Sections
- 📈 SEO Optimized and Schema Integrated
- 🌐 Multi-language and Multi-currency Ready
- 🧩 Custom Script & App Embedding Support

## Installation

1. Go to your [Shopify admin panel](https://www.shopify.com/login)
2. Navigate to **Online Store > Themes**
3. Click **Upload theme** and select the `.zip` file of **Waseem UXUi 2.0**
4. Once uploaded, click **Customize** to start editing your store with powerful section settings


## Customization Guide

- Use the **Theme Editor** to drag, drop, and edit sections on the homepage, product, collection, and other pages.
- Customize typography, color schemes, layout styles, and animation effects directly in the theme settings.
- Use metafields for dynamic product content like specifications, tabs, and icons.
